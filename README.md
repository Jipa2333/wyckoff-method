# wyckoff-method

威科夫操盘法 · 蒸馏知识包（Agent Skill）

把孟洪涛《威科夫操盘法》（山西人民出版社，2016）全书方法论蒸馏为 IF(观察到X) → THEN(判断/操作Y) 决策规则的 AI 技能包，供 LLM 助手在分析 K 线图 + 成交量时直接套用。

## 这是什么

不是书摘，不是读书笔记合集。这是一个**可执行的决策规则库**：

- **核心心智模型**：供求关系是一切判断的理论基础。价格=买卖结果，成交量=努力，走势速度=力度。K线形态和指标只是表象（第一层面），供求才是本质（第二层面）。
- **对手盘视角**：CM（主力机构）在底部制造恐慌逼公众割肉、在顶部制造狂热诱公众接盘。分析的目标 = 读出 CM 的意图，在消息公布前跟随 CM。
- **铁律驱动**：禁止无吸筹过程抄底；禁止熊市找 Spring；禁止突破当下追进；任何位置出现放量阴线 → 无条件离场。

## 使用方法

### 作为 OpenClaw / Agent Skill

将整个目录放入你的 skills 目录（如 `~/.openclaw/workspace/skills/wyckoff-method/`），Agent 会在分析股票/期货走势时自动加载。

### 人工深度检索

```bash
python3 scripts/search_knowledge.py --base references --query "<主题>" --top 5
```

### 分析一张K线图的标准流程

1. **定背景** → `ch1-tools.md`：牛市/熊市/TR？需求还是供应控制？
2. **判阶段** → `ch2-accumulation.md`（底部）或 `ch3-distribution.md`（顶部）
3. **找触发** → `ch4-spring.md`：Spring 种类决策树
4. **定计划** → `ch5-synthesis.md`：进场+止损+目标+危机管理
5. **走全流程** → `ch6-cases.md`：六阶段可勾选清单

## 速查（示例）

| 观察（IF） | 判断（THEN） | 操作 |
|---|---|---|
| 天量极宽阴线（熊市中） | SC，或近底 | 待 ST+吸筹，禁抄底 |
| 吸筹区 JOC/SOS + 缩量小蜡烛回测 | 首选进场点 | 进场 |
| 终极震仓/弹簧效应后的缩量二次测试 | 全书风险最低抄底点 | 进场 |
| 牛市新高长阳+天量（BC） | CM出货预警 | 准备离场 |
| 任何持仓遇放量阴线 | 供应恢复 | 无条件离场 |

完整速查表见 `SKILL.md`。
