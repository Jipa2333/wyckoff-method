# 威科夫操盘法 · 第三章「威氏逃顶策略：识别主力派发」蒸馏笔记

> 读者设定：会读 K 线与成交量的 AI 交易分析助手。本章只解决一个问题——**牛市是否到顶、CM 是否在派发**，以及在派发的哪个阶段离场/做空。

## 方法论（作者心智模型）

**牛熊转换的唯一理论根据：供应。** 牛市结束不是因为"涨多了"，而是因为股票供应量开始大量进入市场 → 需求耗尽 → 供应完全控制市场。价量关系中看到这条链成立，牛市即结束。**只要供应没有扩大的证据，任何顶部信号都不作数**——这是全章总开关。

顶部充满谎言（CM 买通媒体、上市公司放利好、制造急涨），唯一目的是让公众在高位接盘。CM 在吸筹期满仓后，先设法把公众堵在场外（震仓、疲劳战术），等需要出货时再利用利好和急涨诱多。因此：**你看到的"好消息+暴涨"，恰恰是最危险的出货背景**。

核心翻译器是**努力与结果（Effort vs Result）**：成交量=努力，价格进展=结果。IF 努力巨大而结果微小 → 供应强劲吸收买盘（停止行为）。IF 价格应该做什么却没做成（该涨不涨、该跌不跌）→ 警告，预期反转。

## 第一节 · 牛市到顶的预警信号

### 规程 A：突破幅度递减（SOT）
1. 只比较**有深度回调（触及上升通道下轨）且创新高**的上升波，量相邻两个上升波顶点的距离。
2. IF 突破幅度逐次递减（尤其趋于零）→ 需求减弱或供应增强，警告。
3. IF 深度回调后的反弹**到不了超买线就折返**（连中线都过不了更佳）→ 需求已经很弱。
4. SOT 必须与 50% 原则联用：SOT=需求减少，破 50%=供应扩大。两者齐现 → 牛市暂停；**若回调带量跌破上升趋势线 → 供应超过需求，派发即将开始，立刻离场，无论盈亏**。
5. 触发后动作：收紧止损，制定出逃计划。

### 规程 B：50% 原则（牛熊分界线）
1. 对当前上升波画 50% 回调位。
2. IF 回调在 50% 上方止住 + 蜡烛与成交量缩小 → 强势，供应耗尽，属正常回调（可视为买点）。
3. IF 回调**不止一次**明显跌破上升波的 50% 且波动/成交量放大 → 供应扩大，牛市受威胁。
4. IF 随后反弹量缩、无法创新高（SOT），或 50% 处的反弹**第二天立刻被拒绝** → 市场已弱，立刻离场是唯一避免灾难的办法。
5. 下降趋势反向使用：反弹无法收复下跌波的 50% = 熊市确认，此时抢反弹是逆市。

### 本节反模式
- 教条地要求回调"正好"到 50%——50% 只是表象，必须同时看回调过程的蜡烛与量能是否缩小。
- 只用一个信号就下结论——SOT、50%、趋势线突破三者要互相印证，且最终靠供应扩大确认。

## 第二节 · CM 的出货过程（四阶段框架）

**框架**：①牛市如何结束 → ②CM 设立派发区并引诱公众买入 → ③测试阶段（最重要，确认派发并接近尾声）→ ④SOW 出现，市场进入熊市。持仓者的目标是阶段②内离场，做空者在阶段③动手。

### 牛市停止四部曲（按顺序出现，警告逐级升级）
1. **初始供应（初次供应）**：牛市中首次放量下跌，或先急涨再放量下跌。仅临时阻止牛市，非终点。→ 动作：预警，做好危机预案。
2. **抢购高潮（BC）**：成交量陡然剧增 + 上涨速度骤然加快（趋势线角度远超 45°，趋于垂直），常为天量创新高。公众在贪婪和利好下疯狂接盘。→ 明确的触顶信号。
3. **自然回落（AR）**：BC 后的回落。低点是 CM 建立的派发支撑（**冰线**），派发完成前 CM 用买单保护它。
4. **二次测试（ST）**：AR 后的反弹。IF ST 缩量（成交量明显低于 BC）→ **成功的 ST，标志牛市终止**。持仓者离场，无论消息多好都不再买入。

### 派发区间的识别（TR）
- AR 低点与 ST 高点构成震荡区（TR）。初期波动猛烈（公众还在抢购），随 CM 不断出货，波动与量能逐渐衰减。
- IF 每次价格回到支撑（冰线）就反弹 + 反弹到 TR 顶部放大量 → CM 在高位派发，启动出逃计划。
- IF 受保护的支撑被**长阴线增量突破** → CM 已撤掉买单（货出完了），熊市即将开始。
- **避免在 TR 内部交易**，耐心等 TR 右手边出现明确的 SOW 或强势特征。

### CM 诱多与驱离手法（用于识别"谎言"）
- 出货前：买通媒体营造利好、伙同上市公司发布业绩/产品利好、制造价格急涨。
- 上涨途中驱离公众：震仓（急跌吓出不坚定者）、疲劳战术（突破后操纵走势枯燥杂乱，让跟风者失望平仓）。
- 推论：散户在 TR 左手边被甩掉，在 TR 顶部被请回来接盘。

### 本节反模式
- 把 TR 当"正常回调"抄底（牛市背景已被初始供应+BC 改变）。
- 因利好消息在 ST 之后买入——作者明确禁止：ST 成功后"无论你有多么好的预期，都不要买入"。
- 看到单日反转蜡烛就惊慌——BC 前的单独反转蜡烛若无卖盘跟随、且被迅速吸收，只是陷阱，不构成威胁。

## 第三节 · 第二阶段：派发的确认（UT 与 SOW）

牛转熊的最终决定因素是**供应的表达方式**。有两个做空点：**①UT（上冲回落）②SOW 之后的回测**。

### 规程 C：上冲回落（UT）
1. 识别：价格试图突破 TR 顶部，1–3 根蜡烛内跌回区间内。突破过程成交量放大（买方努力大）。
2. 意义：CM 扫空头止损 + 测试突破后的需求；跌回区间=突破无需求跟进，供应控制市场。典型"努力没有结果"。
3. 确认：UT 之后出现**放量下挫**（跟随）。
4. 动作：IF UT + 放量跟随 → 做空进场点 1；持仓者视为最后警告。

### 规程 D：弱势信号（SOW）
1. 识别：放量长阴，**必须出现在 TR 右手边**才有效。两种形态：TR 内的放量下挫（供应控制、努力向下突破），或直接带量跌破冰线（**破冰**）。
2. 确认：SOW 之后紧接着**无量上涨**（低量小蜡烛反弹）。若 SOW 之后反而出现相对大阳线+递增成交量（新需求接盘），则 SOW 失效，按再吸筹对待。
3. 冰线比喻：价格跌破冰线后回测冰线，若遇到"厚冰"（强大供应）则再次下沉——即破冰后的无量回测本身就是做空点。
4. **LPSY（最后供应点）**：SOW 之后的小量小蜡烛反弹。最佳做空点；对持仓者是"最后一班车"。

## 第四节 · 案例验证检查清单（非行情复述）

### 完整派发链核对表（黄金、白糖、美元案例共性）
按序核对，链越完整，派发结论置信度越高：
- [ ] 背景：上升趋势中出现初始供应（放量下跌 / 先急涨后放量下跌 / 波形成交量创新高但突破幅度极小）
- [ ] BC：天量 + 加速上涨（角度陡于 45°），或"波形成交量天量 + 突破幅度递减"充当 BC
- [ ] AR 低点 = 冰线；回落中"小蜡烛 + 成交量增长"= 停止行为（CM 在护盘建仓）
- [ ] ST 成功：ST 成交量显著低于 BC（如 1800万 vs 4200万手）→ 需求耗尽，牛市终止
- [ ] TR 右手边出现 UT（缩短的蜡烛 + 大增的成交量 + 跌回区间）或 SOW（放量长阴破冰）
- [ ] SOW 被**无量回测**确认（反弹量远低于下跌量；时间上反弹天数多但无进展=努力无结果）
- [ ] 做空/离场执行点：UT 处、SOW 后的回测处、LPSY 处；破冰后的任何无量回测冰线都是做空时机

### 低位派发识别清单（SOW 之后的"做底"假象，2015 A股案例）
- [ ] 区间回升过程成交量随价格上升**递减** → 无需求加入
- [ ] 区间顶部（供应区）出现 UT
- [ ] 区间背景有放量下挫（SOW 或初次供应）
- [ ] 三项齐备 → 派发，抄底者**必须离场**
- [ ] 想证明是吸筹？必须看到 SOS——没有看到 SOS 就没有理由持有

### 无 BC 的派发识别清单
- [ ] 牛市末期蜡烛与成交量逐步递减（需求耗尽），无天量新高
- [ ] 确认信号：回落中供应剧增（放量下挫），TR 内每次反弹量随价涨递减、随后立刻放量下挫

### 头肩顶的威科夫解读（图形必须服从供求）
- 左肩 = 初始供应（要求：回落幅度与成交量都扩大）
- 头 = 抢购高潮（超长阳线+天量；从头部下跌若出现 SOW，则右肩确认派发）
- 右肩 = 测试（小量小蜡烛的 ST；或测试时出现 UT）
- 反模式：**死记图形**——头肩顶位置/间距不必完美，没有供求理论根据（供应大举进入、需求无法应付）的图形不构成交易依据。

### 案例中的重要细节规则
- **CM 降价的信号（最易忽视的熊市证据）**：成交量略增但**收盘低于前一天**——说明 CM 开始降价满足公众"捡便宜"的需求。作者称这是"最重要的熊市信号"。
- **高量反弹却不突破 TR 顶部 = 陷阱**（买方巨大努力无果，供应仍强劲）。
- **熊市中第一次无量上涨**（急涨但量小）= 空头回补/散户抄底，非需求，熊市未结束。
- **弹簧效应也可能失败**：放量强弹簧后价格无进展，反而证明供应强大（自我否定），随后 SOW 确认。
- **支撑的两个内涵**：①该价位买家需求大；②大资金保护。反弹弱（量缩）说明大资金不愿保护 → 支撑将失效。
- **反转蜡烛的处理**：出现后等两点——有无跟随（供应是否持续）；卖盘是否被新需求立刻吸收。无跟随+被吸收=陷阱，牛市继续。

## 第五节 · 总结（操作纪律）

- 震荡区出现时**只在右手边行动**：等 SOW（派发）或 SOS/弹簧（吸筹）出现，进场点在其**回测**中。不在 TR 内部猜方向。
- 识别牛终熊始是风控核心：宁可早走，不可在 TR 内"再等等"。
- 下跌速度快于上升，做空利润兑现更快——但前提是 SOW 已被无量回测确认。

## 反模式汇总（公众顶部常犯的错）
1. 把派发 TR 当回调抄底；把低位派发区当"做底"。
2. 相信媒体利好、在 ST 之后因"好预期"买入。
3. 把 BC 的急涨当牛市加强追入。
4. 熊市中抢反弹（反弹不过下跌波 50% 即逆市）。
5. 一见头肩顶图形就开仓，不看供求确认。
6. 把 CM 护盘的支撑当铁底——CM 撤单后支撑瞬间失效。
7. 在震荡区内部/左手边交易，不等右手边 SOW/SOS。
8. SOW 后把"利空出尽"当底——可能是再派发，无 SOS/弹簧确认就不是底。
