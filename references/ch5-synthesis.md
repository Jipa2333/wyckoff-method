# 《威科夫操盘法》第五章 — 综合分析：交易机会、进场点、危机管理（蒸馏版）

> 本章是方法论落地章：24 个实盘图例，每张图都走完整闭环「背景判断 → 价量分析 → 交易计划（进场/止损/目标）→ 危机管理」。下游 AI 套用本文件即可按同一闭环分析任意 K 线图。

## Methodology（作者的心智模型）

1. **市场本质交易法**：每次分析先立「理论基础」，再到图上找能确认该基础的价量行为。例：理论基础=突破阻力；确认=阻力上的卖盘被需求全部吸收（放量但价格不跌 / 突破后低量回测）。理论+确认=判断；缺一不动手。
2. **背景决定一切**：第一眼永远回答两个问题——趋势是什么？谁在控制市场（需求还是供应）？熊市=供过于求，只有需求上来并吸收全部供应才反转；牛市反转的必要条件是**供应扩大**，单靠需求匮乏只会回调不会反转。
3. **做耐心的聪明钱（CM），不做争先恐后的公众**：CM 有消息和资金优势，公众读消息=猜大小。你要做的只是从价量读出 CM 的意图，在消息公布前跟随 CM。所有「公众追单状态」（抢突破、抢抄底、追高）都是离场或反向信号。
4. **努力与结果**：巨大成交量（努力）没有产生相应价格变动（结果）= 被吸收。放量不涨=卖盘被接住（看多），放量不跌=买盘在 bag holding（看多）；低量小蜡烛的上涨=无需求（看空）。
5. **因果律**：吸筹是因、上涨是果。没有吸筹阶段的 V 型急涨「像飞机没跑道」，不做。UT（上冲回落）= CM 引诱公众接派发盘的因，随后必跌是果。

## Core procedures

### P1 标准分析流程（每张图必走）
1. 定背景：牛市 / 熊市 / 震荡区（TR）；当前由买盘还是卖盘控制。
2. 画线：阻力（供应线）、支撑（需求线）、冰线（前期阻力转供应区）、趋势线、超买/超卖线（连接连续波峰/波谷）、关键 50% 回调位。
3. 找关键行为：恐慌抛售(BC)/抢购高潮、停止行为、SOS/SOW、JOC、Spring、UT、死角、SOT（涨幅缩小）。
4. 判断供求关系：回调/反弹是否有量跟随；供给是否枯竭；需求是否扩大。
5. 出交易计划：进场点 + 止损位 + 第一目标 + 危机管理规则。**四要素缺一就不交易。**

### P2 交易机会识别（IF-THEN 规则）

**做多机会（背景须配合）：**
- IF 熊市中出现恐慌抛售（BC，天量长阴）且随后二次测试**缩量**（远低于 BC 量）→ 卖压减轻、CM 接盘，转入吸筹观察。
- IF 疑似吸筹区出现**向上 JOC**（放量长阳跳离区间）或**向下震仓后迅速反弹** → 吸筹确认，方向转多。
- IF 牛市回调至支撑且回调量为低量小蜡烛（无供应进入）→ 供应没上来，价格会继续涨，准备进场。
- IF JOC/SOS 之后第一次回测跳离点**缩量+小蜡烛** → 最佳进场点。
- IF 牛市支撑上出现 Spring（破支撑但收回、收高、量不大）→ 停止行为；IF 随后二次测试缩量 → 进场（高量 Spring 须等跟随阳线确认）。
- IF 垂直需求柱（放量长阳）形成 → 柱底=支撑；IF 日后低量回测该底 → 进场。
- IF 阻力区测试时无量回落（卖盘未涌入）→ 阻力无威胁，等 JOC。
- IF 死角中需求>供应 → 死角后大概率向上突破。

**做空机会（背景须为供应控制）：**
- IF 熊市/TR 顶部出现无需求反弹（反弹=小蜡烛+小量/递减量）→ 做空，目标=前支撑/50% 位。
- IF 价格反弹至阻力（冰线）出现停止行为（SOT 涨幅缩小、长上影、UT）且**随后有卖盘跟随**（放量阴线）→ 确认 UT，在下一轮回测阻力时做空。
- IF 跌破冰线（支撑）后 1–3 根蜡烛内反弹缩量、无法收回冰线之上 → 供应控制，做空。
- IF 死角向下突破 + 反弹测顶无量（4 根以上小蜡烛+低收盘）→ 做空，第一目标=上坡 50%。
- IF 熊市中出现空头回补式急涨（放量长阳后迅速带量回落抹掉涨幅）→ 非需求，不做多；随后的无需求反弹是做空点。

### P3 进场点规则（可执行量化）
- **首选进场**：JOC/SOS 后回测跳离点，条件=回测蜡烛小+成交量明显缩小（供应枯竭）。不满足=纪律性放弃，「这是纪律」。
- **50% 铁律**：回调深度 < 上涨波 50% = 正常回调，趋势未受威胁；> 50% = 趋势受威胁，放弃原方向计划，转观察。
- Spring 进场前提：二次测试缩量确认供应枯竭；高量 Spring 须等带量阳线跟随确认需求吸收。
- 目标位设定：第一目标=最近的供应线/阻力/超买线/冰线；到位后减仓并盯是否出现反向停止行为。
- 入场后必须立即见到「强势确认」：连续上涨+成交量递增。这是持仓的 validity check。

### P4 危机管理（止损 / 强制离场）——独立规则集
- 止损位：放在触发形态的极值外侧（日线最低点下方一个点 / Spring 低点下方 / 做空则放阻力上方）。
- **无条件离场信号**（出现任一，无论盈亏）：
  1. 放量阴线 + 供应恢复（「如果接下来是阴线且成交量增长，无论当时是否亏赚，一定出场」）。
  2. 进场后期望落空：期待强势上涨+递增量，实际出现小蜡烛+小量反弹（无需求）→ 立刻出场。
  3. 放量回测跳离点/支撑（回测应为缩量，放量=供应仍在）→ 放弃进场或离场；二次回测仍是高量阴线 → 永久放弃该计划。
  4. 做空后：下跌必须伴随递增量；若出现长阳（需求吸收供应）→ 立刻离场。
  5. 价格在超买状态回落且回落带量（卖盘随回落增加）→ 减仓/离场。
- 突破蜡烛的跟随检查：突破后回调不得跌破突破蜡烛低点、不得深过 50%；若跌破第二支撑，等 1~3 波 50% 位置且须缩量才考虑接回。
- 套票处理（浮动供应大导致 UT 回落）：不盲目在支撑抄底；等「阳线突破关键测试蜡烛高点」或「二次低量测试支撑」再进；若放量向下突破支撑 → 离场等候。

### P5 选股：相对强弱（RS）流程
1. 打大盘日图作基准；从强势板块选龙头股逐一对比。
2. IF 大盘创新低而个股**不创新低**、坚守某支撑（回调<50%）→ 有大资金在恐慌中收购（巴菲特买高盛案例）。
3. IF 大盘恢复上涨时个股涨幅>大盘 → RS 确认，列入交易对象。
4. 对入选个股再按 P1–P4 流程找进场点；仍须等 JOC/吸筹确认，不因 RS 强就追。

### P6 反模式（作者明确警告，禁止操作）
- ❌ **熊市随意抄底**——铁律。反转必须等到需求占上风（放量吸收全部供应）之后。
- ❌ 没有吸筹阶段的 V 型急涨中追涨——无因无果，涨不长。
- ❌ 供应控制背景下抄 Spring 的底——「卖盘控制的市场，Spring 是做空信号」，必须二次测试缩量确认。
- ❌ 放量长阳追突破——那是 CM 出货/引诱公众，真正的进场点是突破后的低量回测。
- ❌ 把无量小蜡烛反弹当需求——无需求反弹=最危险的陷阱（做多的坟场/做空的信号）。
- ❌ 看到停止行为不盯跟随——停止行为后必须有跟随确认；无跟随=原趋势未变。
- ❌ 把低量小碎步下跌当供应扩大——那是 CM 缺席让市场枯燥下滑甩掉公众，少量需求进入即反弹；此时割肉=把筹码交给 CM。
- ❌ 跳过危机管理直接进场——「交易计划+危机管理」与方向判断同等重要。

## Quick reference（速查表）

| 场景 | 信号 | 动作 |
|---|---|---|
| 熊市 | 恐慌抛售+缩量二次测试 | 转吸筹观察，不进场 |
| 吸筹区 | JOC 或震仓后速弹 | 方向转多 |
| JOC/SOS 后 | 缩量小蜡烛回测跳离点 | **进场**（首选） |
| 牛市回调 | 低量小蜡烛至支撑 | 等停止行为进场 |
| 支撑上 | Spring+缩量二测 | 进场（高量 Spring 等跟随） |
| 阻力处 | SOT/UT+放量阴跟随 | 反弹做空 |
| 破冰线后 | 1–3 根内缩量反弹收不回 | 做空 |
| 任何持仓 | 放量阴线出现 | **无条件离场** |
| 进场后 | 小蜡烛+小量反弹（无需求） | 离场 |
| 回测 | 放量（应为缩量） | 放弃/离场 |
| 回调 | >上涨波 50% | 趋势受威胁，放弃原方向 |

术语：CM=主力机构；BC=恐慌抛售；SOS=放量上涨信号；SOW=放量下跌信号；JOC=放量跳离区间；LPS=最后支撑点；TR=交易区间；UT=上冲回落；Spring=破支撑快速收回；SOT=涨幅缩小（停止行为）；死角=趋势线与阻力交叉的相持区；bag holding=买方张口袋接盘（放量不跌）。
