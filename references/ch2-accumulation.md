# 威科夫操盘法 · 第二章 吸筹（Accumulation）— 蒸馏版

读者对象：会读 K 线（蜡烛）与成交量的 AI 交易分析助手。目标：判断吸筹阶段、定位最低风险进场点。

## 方法论（作者心智模型）

- **一切从供求关系出发，不从形态出发。** 熊市=供过于求；牛市=供不应求；底部震荡区=供求平衡但 CM 持续吸走供应。看走势先问"这背后的供求变化是什么"，再问"像不像某个形态"。
- **两个对手盘**：CM（主力机构，唯一有能力在熊市接盘的资金） vs 公众（顶部满仓、底部恐慌割肉）。CM 的全部手法——恐慌抛售后的萧条、疲劳战术、震仓——只有一个目的：迫使公众交筹。识别 CM 行为=跟住主力脚步。
- **确认链**：一个行为必须由下一个行为确认，直到局面明朗。PS 需 BC 确认；BC 需 ST 确认（ST 成功=熊市终止）；SOS/JOC 需缩量回测确认。任何一环缺确认，不进场。
- **左手边/右手边**：恐慌抛售到自动反弹属左手边（禁止抄底）；从二次测试开始属右手边（可以开始找进场点）。吸筹进场总原则：**必须在震荡区右手边、测试确认之后进场**。
- **过马路比喻**：CM 吸筹=人群过马路——先在一边聚集（吸筹区），左右观察（测试供应），然后快速通过（JOC/SOS 跳离），到达另一边（牛市）。震仓=过马路前回头看一眼，扫掉掉队者。

## 规程一：熊市终止的四个市场行为（§1）

依次寻找以下四步，全部清晰出现才可判定熊市终止：

1. **初次支撑（PS）**：熊市持续无反抗下跌中，出现放量+下影线的蜡烛，使下跌停止。
   - IF 熊市中未见需求进入 → THEN 任何抄底信号（系统/消息/指标）都属高风险，忽略。
   - IF PS 后 CM 逢高出货 → THEN 只是临时支撑，不是吸筹开始；IF 随价格下跌继续收购 → THEN 可能进入吸筹。
2. **恐慌抛售（BC）**：超长阴线+超高成交量（一天或连续几天），公众割肉、CM 接盘。
   - IF 未见此类价量 → THEN 恐慌抛售尚未出现，熊市未终止。
   - IF BC 后出现窄幅横盘 → THEN 危险，熊市可能继续，提高警惕。
   - 含义：主力需求已进入，但**不到进场时机**，等二次测试。
3. **自动反弹（AR）**：BC 后的正常反弹，多为空头回补。
   - **禁止在此抄底。** 不代表熊市结束，随时可能掉头遭遇震仓。
4. **二次测试（ST）**：AR 后价格回落再次试探 BC 低点。判定：
   - IF 回落为小蜡烛+大幅缩量（相对 BC） → THEN 成功的 ST = 熊市终止信号。→ 可开始关注右手边机会。
   - ELSE IF ST 中成交量仍大（甚至接近 BC） → THEN 浮动供应还在，熊市未止，等下一次 ST，直到发现供应耗尽。
   - IF ST 高量但低于 BC 量 → THEN 也算 ST，但需等待进一步测试确认耗尽。
   - 成功的 ST 同时确认 BC 低点支撑有效；若日后吸筹中急速跌破该支撑 → 属终极震仓，吸筹近结束。

## 规程二：停止行为（Stopping Action，§2）

两种价量背离，出现即"趋势暂时停止"的提醒，不等于反转：

- **类型 A（影线型）**：下跌中 = 长下影+放量；上升中 = 长上影+放量。是暂时停止。
  - IF 上升中出现放量长上影 → THEN 后续三种可能：(a) 短暂缩量回调后立刻创新高=暂时供应，牛市继续；(b) 随后进入震荡区=可能派发，防下跌；(c) 随后放量急涨=初次供应（超买预警）。
- **类型 B（缩量滞涨型，更隐蔽）**：价格创新低（或波幅大幅缩小）但成交量显著放大——卖盘努力没有产出相应跌幅，说明需求（买盘）正在吸收卖盘。
  - IF 此行为发生在震荡区右手边 → THEN 大概率引发大幅上涨，是买入时机。

## 规程三：吸筹第二阶段——震荡区拉锯与进场点（§3）

**识别清单（震荡区内逐条核对）：**
- 早期波幅和成交量较大，随时间推移逐渐缩小（卖单流入越来越少）。
- **核心条件：上涨波的力度和成交量必须大于下降波**（需求持续扩大、供应持续枯竭）。不满足=不是正常吸筹。
- CM 在顶部布置卖单控制价格（每次反弹到区间顶部即被打回）。
- 疲劳战术特征：每次小幅反弹吸引抄底者→立刻打压→缓慢枯燥阴跌，反复折磨公众至绝望抛售。

**三个进场位置（按安全性排序）：**
1. **SOS/JOC 之后的缩量回测**——最安全。唯一要求：回测必须是小蜡烛+低成交量。
2. **成功二次测试后，震荡区底部的弹簧效应（Spring）**——前提是已确认上涨波>下降波。IF Spring 仅小幅破支撑 → THEN 可直接进场；IF Spring 大幅破支撑伴随放量 → THEN 必须等二次测试（同样要求缩量小蜡烛）。
3. **终极震仓中直接进场**——风险略高；等震仓后的二次测试进场更稳（要求同上）。

**进场后验证（强制）：**
- IF 进场后价格和成交量递增 → THEN 牛市强，持仓。
- IF 进场后出现放量阴线 → THEN 遇到大量供应，**立刻出场**。

## 规程四：吸筹第三阶段——CM 测试供应（§4）

- 本阶段 CM 只做一件事：测试市面上股票是否被吸收完。主工具=终极震仓（深幅跌破区间底），变体=弹簧效应（小幅破支撑即返回）。
- IF 观察到深度跌破吸筹区底部支撑 → THEN 判断为终极震仓信号 → 等待其二次测试。
- **终极震仓/弹簧效应后的二次测试 = 全书风险最低的抄底点。**
- 判定测试成功：回调过程缩量+小蜡烛。IF 测试后 CM 只能抬价收筹（低点抬高） → THEN 底部筹码已尽，牛市条件成立。

## 规程五：吸筹第四阶段——进入牛市（SOS / JOC，§5）

- **SOS（强势出现）**：震荡区内长阳线+明显增高成交量 = 需求控制市场的信号，也是震荡区可能终止的信号。
  - SOS 不总由一根蜡烛完成：IF 连续 2–3 根阳线、更高最低价/收盘价/最高价+递增成交量 → THEN 等同 SOS（常见于支撑反弹成功后）。
  - **SOS 必须经回测确认**：IF 回测为缩量小回调 → THEN 确认有效，进场；IF 回测出现放量长阴 → THEN SOS 立刻失效，价格继续在震荡区波动，放弃。
  - IF SOS 后出现横盘（无回测无跟随） → THEN CM 可能在出货，警惕派发。
- **JOC（跳过小溪）**：放量长阳快速突破震荡区顶部阻力。JOC 是 SOS 的特例（SOS 突破区间顶=JOC）。
  - 必须发生在震荡区右手边；突破后成交量必须有跟随；回调不得出现放量阴线，否则 JOC 失效回到震荡区，耐心等待新机会。
  - **操作**：JOC 形成=进场平台搭好。等价格回测突破点（原阻力变支撑），IF 回测为小蜡烛+低量（或出现停止行为/强反弹） → THEN 进场。IF 回测放量 → THEN 观望，等供应耗尽的新二次测试。
- **突破前的探索阻力**：牛市中价格上冲回落（UT）不一定是反转。
  - IF 上冲回落出现在需求控制市场的背景下，且成交量未放大、回落停在反弹 50% 以上 → THEN 属"探索阻力"而非终止行为，是牛市继续+进场的预备信号。
  - 垂直供应柱的顶部=主要阻力（小溪），价格常回测之；回测缩量=供应枯竭。
- **牛市中的枯燥窄幅盘整**：先看背景（上升趋势中多为再吸筹），再看轨道顶部是否有供应进入（无供应+收盘居中部以上=需求仍占优），不要因无聊离场——CM 故意用枯燥驱离公众。
- **危险信号（顶部预警）**：垂直急涨+顶部放天量+趋势线角度突然变陡 = 超买/抢购高潮，CM 可能开始派发；随后若反弹无力创新高（量还在、波幅缩小=努力无结果） → 逐步平仓，防 SOW。

## 规程六：综合案例提炼出的验证清单（§6）

案例不复述行情，提炼可复用的检查点：

- **死角（Dead zone）**：支撑上蜡烛越来越短、无新高无新低、量极度萎缩=供求双弱、筹码稀缺。IF 出现在需求渐扩背景下 → THEN 最佳低风险进场点，扣扳机依据是"死角"本身，不是某根蜡烛或指标交叉。
- **支撑逐次抬高**：CM 在低价位买不到货被迫提价=吸筹确认、牛市孕育信号。
- **SOS 后回测的支撑反弹=LPS（最后支撑点）**，又一个安全进场点。
- **吸收过程（Absorption）**：价格进入供应区（前高套牢区），放量但蜡烛高位收盘=公众保本抛盘被需求全部吸收。只发生在 SOS 之后，看涨。
- **SOT（突破幅度缩小）**：比较相邻蜡烛/波峰/波谷的突破幅度——努力持续但进展越来越小=停止行为。IF 在测试主要支撑/阻力时出现 SOT → THEN 立即进场。
- **熊市恢复确认**：跌破小型上升趋势线+收盘低于前日=熊市继续，此前的"震仓"假设作废。
- **天量上涨预警**：牛市不需要天量，匀速上涨才是健康；天量急涨=抢购高潮，供应大量涌入，有仓位者预警。
- **长期吸筹中**：BC 后的 SOS 若成交量随上涨递减（突破无后续力量） → 必有一次回调/二次测试，其质量决定能否进场；失败则放弃。

## 规程七：没有恐慌抛售的底部（§7，A 股常见）

- A 股底部常无 BC。CM 只有两种替代手段逼公众割肉：
  1. **拖**：震荡区拉长到数月~数年，反复"反弹→阻止上涨→枯燥阴跌"，磨到散户割肉（如 2009–2014 上证）。
  2. **多次终极震仓**：幅度要更大，制造恐慌气氛。
- 操作不变：无 BC 则不急着判定熊市终止；等 JOC/SOS 出现（=需求彻底控制市场），其后的缩量回测=安全进场/加仓点。

## 规程八：震仓（Shakeout，§8）

**终极震仓（吸筹末期）识别清单：**
- 前置形态（预警）：震荡区内每次反弹到不了前高、高点呈台阶式下降=浮动供应还在 → 容易出现震仓。
- 触发：急速大幅深跌，**跌破所有支撑**，随后快速反弹收回区间内。
- IF 跌破后迅速反弹（尤其带量反弹形成 SOS） → THEN 确认震仓 → 等缩量回测进场/加仓。
- 卖方=公众（高位套牢者+盲目抄底者），买方=CM。震仓后必须看到牛市特征的跟随：连续的更高最高价/最低价/收盘价+稳定递增（非暴增）的成交量。
- **铁律：底部若既未见终极震仓（或弹簧效应后的测试）也未见 SOS/JOC，不要抄底。**
- 特殊情形：测试可以是放量宽幅阴线（浮动供应仍存在），此时等下一根强反弹蜡烛确认供应被吸收，再决定是否进场；走势不按预想走时，随时有出场预案（二次震仓也是常见剧本）。

**普通震仓（牛市中途，洗盘）：**
- 背景=上升趋势，无任何供应征兆下价格突然急跌（多为突发消息引发公众临时恐慌抛售，CM 照单全收）。
- IF 震仓伴随大成交量 → THEN 必须等二次测试（缩量+小振幅）才能进场；盲目抄底遇新供应会被锁。
- IF 二次测试量极小 → THEN 供应耗尽，牛市快速恢复。

## 反模式（作者明确警告，吸筹区公众常犯错）

1. **盲目抄底**："跌得越深越该买"是情绪赌博。未见需求扩大，一切抄底信号皆高风险。
2. **在自动反弹（熊市第一次反弹）抄底**：那是空头回补，不持续，易遭震仓。
3. **在左手边抄底**：PS→BC→AR 区间不进场；从 ST 成功起才算右手边。
4. **只看眼前蜡烛/图形/指标**（表象交易）：必须问价量背后的供求理论根据。
5. **见到反弹就以为吸筹结束**：区间内每次反弹都被 CM 打压=吸筹未结束；供应未枯竭前，牛市孕育未成熟，无视一切抄底消息。
6. **SOS/JOC 后追价不回测**：进场平台出现后要等缩量回测，回测放量=有供应，不进场。
7. **测试 JOC 时供应扩大仍硬进场**：放量大阴线回测=放弃，等新二次测试；若测试放量且破支撑=直接放弃该机会。
8. **牛市中见上冲回落（上影线）就当反转**：需求背景下的 UT 多为探索阻力，看供应是否跟随再定。
9. **天量急涨时贪焚加仓**：垂直急涨+顶部天量=超买/抢购高潮，是 CM 派发预警而非利好。
10. **在震荡区内部频繁交易**：小区间内不参与，容易亏损；等 SOS 或 SOW 出现再动。

## 速查表（决策序列）

| 阶段 | 触发观察 | 判定 | 动作 |
|---|---|---|---|
| 熊市 | 持续无反抗下跌，无需求 | 进行中 | 不抄底 |
| 第一步 | 放量长下影止跌 | 初次支撑(PS) | 关注，不动 |
| 第二步 | 超长阴+天量 | 恐慌抛售(BC) | 关注，不动 |
| 第三步 | BC 后反弹 | 自动反弹(AR) | 禁止进场 |
| 第四步 | AR 后缩量小回落 | 成功二次测试(ST) | 熊市终止，进右手边 |
| 二阶段 | 涨波>跌波，量缩 | 吸筹进行中 | 3 个进场点按序选择 |
| 三阶段 | 深破所有支撑后快反弹 | 终极震仓 | 等二次测试进场（风险最低） |
| 四阶段 | 长阳放量突破区间顶 | SOS/JOC | 等缩量回测进场 |
| 确认 | 更高高/低+递增量 | 牛市 | 持仓；放量阴=离场 |
| 预警 | 垂直急涨+顶部天量 | 抢购高潮 | 减仓，防派发 |
