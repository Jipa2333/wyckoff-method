# 《威科夫操盘法》第一章 — 聪明钱解读市场的工具（蒸馏笔记）

> 用途：供 AI 交易分析助手在看 K 线图+成交量时直接套用的操作规程。
> 术语：CM=主力机构；SC=恐慌抛售/Selling Climax；BC=抢购高潮/Buying Climax；AR=自动回落；ST=二次测试；PS=初步支撑；JOC=跳过小溪；SOS=力量信号；SOW=弱势信号；UT=上冲回落；TR=交易区间；SOT=停止行为；VDB=垂直需求柱；VSB=垂直供应柱；Spring=下冲反弹/弹簧效应。

## 方法论（作者的心智模型）

价格、成交量、走势速度是聪明钱的三个基本要素；**供求关系是解读一切走势的理论基础**。K 线和技术指标只是表象（第一层面），供求关系才是本质（第二层面）。每一笔价格变动都可翻译为"谁在控制市场——买方还是卖方"。

跟踪趋势的真正含义 = 利用供求关系跟踪 CM 的操作意图。CM 掌握大资金，会操纵价格表象引诱/逼迫公众犯错（顶部制造狂热引人入市，底部制造恐慌逼人割肉）。公众的判断依据如果来自指标背离、赌、怕错过，而非供求理论根据，结局就是套牢。

三大分析原则贯穿全书：
1. **供求关系原则**——趋势的动力来自供求不平衡；
2. **因果关系原则**——趋势形成前必须有准备过程（吸筹/派发的交易区间），无因则果不持久；
3. **努力与结局原则**——成交量是努力、价格进展是结局；努力未产生应有结果 = 停止行为，方向即将变化。

## 按节规程

### 第一节 聪明钱的看盘顺序

每根 K 线按五步解读，顺序不可乱：
1. **背景**：当前处于什么趋势/什么阶段（牛市、熊市、TR、吸筹、派发）？
2. **价量形态**：蜡烛长度、成交量高度、变化速度。
3. **性质**：走势强弱如何？这个形态的原因是什么、可能产生什么后果？
4. **结论/预测**：洞察 CM 意图，结合供求关系判断方向。
5. **措施**：进场、出场、持有、等待。

- IF 牛市中回调的蜡烛和成交量都递减 → THEN 供应未进场，价格还会尝试上涨；等出现停止行为或需求接盘迹象进场。
- IF 牛市中回调阴线实体开始扩大，且成交量相对偏大 → THEN 供应在扩大，不能做多；耐心等供应耗尽（量缩、蜡烛变短）再进场。
- IF 熊市中价格持续急速下跌、中间无任何反弹（超卖） → THEN 至少会有反弹，但**禁止立刻抄底**——没看到吸筹准备过程前，CM 不会拉价帮被套公众解套。
- IF 下跌中出现极宽振幅+天量（SC 恐慌抛售） → THEN 下降趋势结束或接近结束；但需成功二次测试才终止熊市。
- IF 反弹蜡烛量超大但为上影线 → THEN 反弹遇强大供应，趋势未变，禁止抄底。
- IF 反弹至阻力位停滞（SOT）+ 成交量扩大 → THEN 顶部供应超需求；随后上涨若量大幅萎缩 → 需求枯竭，熊市未改。
- IF 支撑位处蜡烛高低范围大幅缩小但成交量未缩小 → THEN 停止行为：供应枯竭+新需求接盘；若随后出现阳线确认需求吸收完毕 → 吸筹结束，可进场。
- IF 跌破通道的速度极快且无反抗 → THEN 疑似震仓；关键看下方支撑能否以"缩量小蜡烛+停止行为"挺住。
- **死角**（支撑/阻力处高点不断降低、低点不断升高、波动收窄） → 预示价格即将大波动，是提前布局的好时机。

### 第二节 CM 观察走势遵循的原则

- 持仓后持续用供求关系验证：IF 后续价量否定你的判断 → 立刻离场；IF 支持 → 持有。
- 因果关系用于判断反转：任何主要趋势反转前必须有准备过程。公众在熊市第一个反弹就买入被套，原因 = 没等吸筹完成。**没有因（吸筹），果（牛市）不会持久。**
- 努力与结果用于识别停止行为：IF 价格触支撑/阻力位时成交量突然扩大但蜡烛很小 → 努力未产生结果 → 大卖单被买单截住 = 停止行为，可提前预知后市方向。

### 第三节 供求关系

翻译规则：价格上涨 = 供不应求；下跌 = 供应大于需求；TR = 供求平衡（最容易亏钱的危险区）。
- IF 高成交量但上涨未取得进展 → THEN 供应开始增加（CM 利润目标已到，暗自出货），背景由供不应求转为平衡/供过于求 → 调整仓位、做出逃准备。此时指标仍显示买入，禁止跟。
- IF 牛市中出现回调 → THEN 关键看回调是否引起供应扩大。IF 供应扩大且恢复中无更大的新需求吸收卖压 → THEN 市场进入派发，随后转熊。
- IF 下跌趋势要停止 → THEN 必须看到需求大量出现并吸收全部供应（卖方不降价也能成交）。
- **抄底的理论根据（价量三件套）**：①天量抛售（SC）→ ②低量测底（ST）→ ③震仓驱离最后浮动供应，或长阳带量离开吸筹区间。三者缺一，禁止言底。
- 止损/纠错逻辑：任何判断都以供求关系理论为基础，再从价量中找证据；证据消失即离场，不用情绪否定市场行为。

### 第四节 公众对支撑和阻力的误解

- **支撑/阻力与任何画线无关**（均线、黄金分割、指标线都不算数）。支撑 = 某价位买单流入远大于卖单流入；阻力 = 某价位卖单流入远大于买单流入。
- 价格回到支撑位时看**反弹力度**（力度 = 需求质量）：
  - IF 触底后无强烈反弹 → 买家在等更低价格，支撑失效。
  - IF 测试蜡烛为小蜡烛 → 供应枯竭，吸引需求进场，支撑有望有效。
  - IF 支撑处放量（大卖单流入）但跌幅缩小 → 努力无结果 = 需求吸收了卖单（停止行为）→ 可轻仓买入+危机管理计划，需求跟随立刻加仓。
  - IF 支撑处放量但蜡烛为阴线且在震荡区右手边 → 供应主导，必须清仓，禁止买入（买入=帮 CM 派发）。
  - IF 支撑上的反弹乏力（涨幅小、收中部、随后上影线放量阴线） → 支撑无效，已抢反弹则立刻出场。
  - IF 进场后数日低量小幅波动（无持续需求跟随） → 支撑假设被否，立刻出场等候。
- 阻力/突破操作规程：
  - IF 价格突破阻力（如冰线/供应线） → 不能立刻进场（突破是公众行为）；等**缩量小蜡烛回调**至突破区 → 需求仍控场，进场；止损放突破蜡烛的低点。
  - IF 阻力处出现一系列收盘相近的蜡烛 → 需求减弱；IF 再有阴线跟随+递增成交量 → 供应扩大，突破无望。
  - IF 阻力处要确认看跌 → 必须看到创新低阴线+递增成交量（供应扩大的理论基础）；没有出现 = 供应未扩大。
  - IF 阻力前形成窄幅通道、量价都低迷 → 供求都不活跃，死角将引爆大行情；稍有力量即可破位。
  - IF 出现超长阳线+放量（抢购高潮 BC） → 供应进场吸收需求；对比随后上涨力度，IF 力度低于 BC 且成交低迷 → 下跌根据成立。
  - **UT（上冲回落）**：突破阻力线又收回其下（上影线；可 2~3 根完成）。IF UT 后无阴线跟随+递增成交量 → 只是试探，禁止做空。IF UT 后回调萧条（小蜡烛小量） → 供应枯竭，等待 JOC。
  - IF 回调低量且无任何卖盘迹象 → 任何低量回调都是进场点。
- 关键价位定义：**冰线** = 上升趋势最后一道防线，取新高前反弹波段的低点（或下降趋势中回调前的反弹低点），冰线上套牢盘成本区；**供应线** = 下降通道上轨，假设每次触及都有大卖单压下，IF 超大成交量+宽蜡烛突破供应线 → 需求吸光卖单，有反转可能（还需供应枯竭确认）；**VDB** 底部 / **VSB** 顶部均为关键支撑/阻力区，价格常回测，可作进出场点。

### 第五节 如何识别供应和需求扩大

- 需求扩大的价量定义（TR 内）：出现在 TR 右手边 + 相对长的阳线（含长下影线）+ 成交量扩大。
- 供应扩大的价量定义：TR 顶部放量 + 上影线（阴线更佳）。
- **VDB（放量长阳）**：底部自然形成支撑区，价格回测此底部时 IF 出现量增+反弹 → 需求吸收供应，进场做多。
- **Spring（下冲反弹）**：价格跌破先前支撑（CM 测试浮动供应）。IF 之后持续上涨并创新高 → 有效；IF 无量能持续 / 不创新高 → 需求乏力，价格回区间或转熊。牛市中连续失败 Spring = 牛市乏力。
- 判断阻力处突破还是反转：
  - 向上突破的根据 = 阻力处无供应扩大 + 需求积极吸收阻力卖盘。
  - 向下反转的根据 = 阻力处大量卖单流入 + 需求无力吸收。
- **JOC**：高量宽振幅强涨突破关键阻力/TR 上边界 = SOS 信号。
- **SOS**：超长阳线+超大成交量（或连续阳线递增量），必须经随后小蜡烛+小量回调确认。
- **SOW**：宽幅递减+成交量巨大，须反弹无力确认。
- 熊市中需求扩大的唯一形态 = **恐慌抛售**：天量超长阴线不是续跌信号，而是天量买盘（CM）接住了天量抛盘（公众）。SC 后 IF 出现首次放量猛烈上涨 → 看盘倾向转牛，但仍禁止进场——须等二次测试确认 PS + TR 吸筹过程 + 浮动供应测试。
- 放量滞跌（SC 后放量但蜡烛变短、跌幅缩小）= 努力无结果 = 停止行为，需求占上风。

### 第六节 牛市中怎么看出供应进场了：抢购高潮

- 牛市终止的根据 = 需求减弱 + 供应大量进场 + 需求无力再主导。
- IF 牛市新高出现长阳+天量（BC） → THEN 需求来自公众（怕错过），供应来自 CM（目标价已到，暗自出货）→ 供应质量优于需求 → 顶部警告。
- 牛市中不希望看到超长阳线+放量——那不是真牛，是 CM 的出货手段。
- IF BC 后回落非常弱（供应未扩大/正消耗） → 价格续涨；通常 BC 后形成自然下跌（AR），随后二次测试。

### 第七节 因果关系

- IF 要判断趋势反转 → 先找准备过程（TR）；**没有看到 TR，一切反转判断不成立**。短反转可在低一级时间框架上找 TR；安全进场点在 TR 右手边。
- 熊转牛价量 checklist（按序核对）：① SC（天量长阴，加速下跌）→ ② 反弹中出现初次支撑迹象 → ③ 震仓扫掉抄底盘、清除浮动供应 → ④ 回测底部确认浮动供应耗尽 → ⑤ SOS（放量长阳离开区间）→ 建仓。SOS 出现 = 趋势开始。
- 牛转熊价量 checklist：① 供应初次进场（长上影+放量 = 第一个供应区/阻力）→ ② 价格回测供应区时供应反复扩大（确认巩固阻力）→ ③ 区间右手边出现 SOW（垂直供应柱）→ 熊市开始。
- **单日熊市开始三条件**（同时满足）：当日最低点和最高点都低于昨日；收盘价低于昨日；成交量 ≥ 昨日。
- 公众抄底三病根：怕错过大底、缺乏市场行为知识、缺乏耐心。作者警告：底部 CM 的吸筹会故意维持枯燥小区间并迫使被套公众割肉——看到"便宜"就买 = 替 CM 供货。

### 第八节 努力与结局关系

- 定义：努力 = 成交量（流入订单总量）；结局 = 价格进展幅度。也可用波段累积成交量对比（更灵敏）。
- **放量滞涨（牛顶危险信号）**：IF 成交量持平/扩大，但蜡烛振幅和涨幅明显小于前一日 → 买方平价即可买到货 = CM 出货施压 → 危险。随后两种演变：回调后恢复上涨；或进入区间、公众怎么努力价格都不涨（最危险 = CM 派发，熊市准备开始）。
- IF 滞涨后再现放量却无法创新高，随后一日量急缩 → 需求耗尽，清仓最后时机。
- **放量滞跌（熊底买入信号）**：IF 成交量扩大、上影线显示大卖单流入，但价格不创新低 → 努力无结果 = 需求全部吸收供应 → 背景转为需求控场 → 买入依据（不来自指标或消息）。
- 波段对比：上涨波累积量逐波放大但价格不创新高 = 警告；下降波量激增 = 供应控场，熊市开始，最后逃命/做空时机。

### 第九节 总结（认知校准）

- IF 看到向上突破 → 先问"CM 是否已完成吸筹/是否愿意让价格涨"，而不是兴奋追买。突破成败取决于 CM 的要求；未完成的突破会被压回，让情绪化公众失望割肉。
- 关键细节常与公众看法相反；大行情的信号藏在不起眼的价量细节里（小而关键），不在长阳长阴下影线这类显眼形态里。
- 所有"新指标用法"都是表象游戏；训练目标 = 不看指标、只从价量细节实时读出供求关系。

## 反模式清单（作者明确警告）

1. 禁止看到大跌/超卖就立刻抄底（无吸筹过程 = 半山腰）。
2. 禁止在反弹遇阻放量（供应扩大）时做多。
3. 禁止突破当下追进（突破是公众行为）；等低量回调确认。
4. 禁止在 TR 右手边放量阴线时买入（等于帮 CM 派发）。
5. 禁止靠技术指标信号、指标背离、消息、赌来做反转判断。
6. 禁止用均线/黄金分割等画线定义支撑阻力。
7. 禁止在 UT 无量无阴线跟随时做空。
8. 禁止在支撑假设被价量证伪后持仓（禁止用情绪否定市场）。
9. 禁止牛市中把"新高长阳+天量"当强势追买——那是 BC 出货。
10. 禁止在吸筹未完成时因震仓/枯燥行情割肉——那是 CM 在收货。
