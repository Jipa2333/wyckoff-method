# 第六章 综合分析结果 + 后记 — 蒸馏笔记

> 本章是全书方法论的实战案例集（23 组图）+ 作者总结。蒸馏目标：**一套拿到陌生股票后从头到尾套用威科夫方法的可勾选流程**，而非行情复述。

## 心智模型

- **判断基于"市场倾向"，不基于形态或指标。** 放量阴线出现后，它反映的是"供应在控制"这个倾向，后续所有解读都服从该倾向，直到被新的价量证据推翻。
- **周期联动：** 日线吸筹结构不明显（V 型反转）时，用小一级周期（小时/5分钟）看吸筹；在小周期进场后，必须等大一级周期出现"跟随"（量增的确认棒）来验证。〔ch5〕
- **用 CM 的视角解读：** 恐慌抛售、震仓 = CM 制造恐怖逼公众割肉；冰线 = CM 为派发而建的支撑，CM 撤防 = 派发完毕。
- **背景优先：** 牛市背景只做回调低吸，熊市背景只做空/观望。翻转背景的必要条件是"需求持续扩大，特别是区间右手边的强势上涨"，否则一切反转信号视为假信号。

## 完整分析流程清单（陌生股票 → 交易 → 离场）

### 阶段 0 · 背景判定
- [ ] 逐波比较上涨波 vs 下跌波的蜡烛长度与成交量：上涨波更大 = 需求占优（牛市）；下跌波量增 = 供应控制（熊市）。〔ch1 三要素、ch5〕
- [ ] 据此定调：需求背景 → 只计划回调买入；供应背景 → 只计划反弹做空，任何 Spring/底部信号先打折扣。

### 阶段 1 · 事件识别（吸筹 or 派发）
- [ ] 熊市末端必须出现停止行为：恐慌抛售（长阴+天量、跌破所有支撑）或震仓。若未见恐慌抛售，预期 CM 在吸收阶段补做震仓。〔ch2〕
- [ ] 恐慌抛售后若反弹无量 = 自然反弹（AR），用它与抛售低点定出 TR 上下边界。
- [ ] 顶部派发证据：阻力区右手边高量阴线、UT（冲高+超买+供应进入）、回测冰层失败。〔ch3〕

### 阶段 2 · 进场触发
多头进场点（任一满足）：
- [ ] **JOC 回测**：跳离区间后回测 JOC 位，回测棒 = 小量+小蜡烛 → 进场或加仓。〔ch5〕
- [ ] **SOS 后低量测试**：SOS 棒之后回调缩量 → 牛市确认，可进。
- [ ] **Spring**：跌破支撑（或前棒 50% 位置）后迅速收回，跌破时低量 → 进场。〔ch4〕
- [ ] **二次测试（ST）**：恐慌抛售/震仓后的第二次探底缩量 = 供应枯竭 → 可先进部分仓，待需求确认后补仓。
空头进场点：
- [ ] 破冰（跌破冰线）后回测冰层。〔ch3〕
- [ ] 反弹未过前下跌波 50%（50% 原则）→ 做空点。
- [ ] 供应背景下的失败 Spring → 本身即做空信号。

### 阶段 3 · 止损放置
- [ ] Spring 进场 → 止损放 Spring 棒（或前一根）下方。
- [ ] JOC 回测进场 → 灾难性止损放"跳离区间蜡烛下方约一个点"（需求起始处）。
- [ ] 进场时即写好止损位，不留到场后临时决定。

### 阶段 4 · 危机管理（进场后 1–3 根、最迟 3–5 根蜡烛内裁决）〔ch5〕
- [ ] 期望看到：阳线跟随、更高的高/低/收、需求吸收供应。
- [ ] 任一危险信号出现 → 无借口减仓/离场：①回测后反弹乏力且量递减（需求没跟上，预期新二次测试，做逃跑准备）；②阴线+量增 = 供应再现（失败的二次测试）；③任何位置的放量阴线 → 立刻离场；④支撑处反弹始终无力 → 需求不够，预期震仓，准备出逃；⑤跌破死角/支撑 → 平仓。

### 阶段 5 · 持仓与目标
- [ ] 趋势健康检查：每次回调量 < 上涨波、低点不断抬高 → 无威胁，持仓。
- [ ] 底部死角（窄幅横盘）：若上涨波量与蜡烛均大于下跌波 = 需求>供应，预期突破；突破死角 = 预期兑现。
- [ ] 第一目标 = 前阻力区（被套公众保本抛售处）。到目标后停顿期间持续高量 = 供应仍在 → 减仓；若再无需求反弹 → 转做空思维。
- [ ] 加仓点 = 下一个无量回测。牛市初中期的低成交量是 CM 策略（不吸引公众），不是问题。

## 推理链示范（看到什么 → 推断什么 → 怎么做）

1. **震仓还是续跌？（图6-2/6-3）** 长阴+天量跌破所有支撑 → 恐慌抛售/震仓候选，两种剧本：随后无需求反弹 = 继续做空；立刻大幅反弹 = 震仓确认，CM 吸筹、底部供应已扫清。后续验证：带量反弹但两日内量急速萎缩 → 需求后继无力；回落量增 → 卖盘未竭；低量小阳线 = 无买家进场 → 续跌。
2. **支撑失效链（图6-4/6-5）** 触及需求线后反弹虚弱、无需求 → 需求线支撑失效，跌破是必然。回调中放量下跌 → 供应控制倾向确立。价格回 JOC 支撑位但量大 → 供应未竭，不符合进场要求，耐心等二次测试。二次测试小量小价差 → 供应真空，需求稍努力即可涨 → 先买一部分，需求出现再补仓。
3. **回测质量裁决（图6-11）** JOC 后回测量大收低 = 供应仍大；随后反弹量递减 = 需求匮乏 → 减仓或出场，跌破死角则平仓。再出阴线放量 = 失败的二次测试 → 彻底放弃做多。
4. **冰线逻辑（图6-16/6-30）** 冰线是 CM 为派发设立的支撑；突破 = CM 派发完毕、撤掉支撑 → 深度下沉。破冰后的无需求反弹 = 下跌延续；回测冰层 = 第二做空点。
5. **关键反转柱（图6-15）** 阻力区右手边出现高量阴线吞没前棒（OKR）= 背景已转熊。"熊市抄底"就是下场。
6. **Spring 的语境依赖（图6-29）** 吸筹背景 Spring = 买点；卖盘控制背景下 Spring 常失败——跌破区间+需求线、需求不恢复 → 不行动；待反弹突破跳空柱（需求战胜供应）才进场。卖盘背景下的 Spring 本身就是做空信号。

## 交易者戒律（后记提炼）

1. **只在吸筹/派发阶段做分析。** CM 不在场时价格移动随意、价量模糊 → 休息，不盲听推荐交易。指标在无关阶段发的信号一律无视。
2. **永远不与众指标组合。** 指标是追随表象的数学公式，无法撼动市场规律；组合 = 走回头路。威科夫方法独立且完整。
3. **不贪多：掌握 1–2 个方法即可盈利。** 作者示范配方：确认需求占优背景（连阳增量，或上涨波量与蜡烛均大于下跌波）＋识别合格回调（更小的蜡烛与量）＋1–2 个停止行为（SOT 或 Spring）= 一套完整系统，反复实战内化成自己的机器。
4. **危机管理是方法的一部分。** 进场后 1–3（或 3–5）根蜡烛内甄别对错，发现过早或误判 → 没有任何借口立刻出场。
5. **记交易日志，每天写**（进场、出场、结果、感悟），坚持复盘。"我们学的不是方法，是盈利。"
