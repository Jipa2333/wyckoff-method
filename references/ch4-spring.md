# 威科夫操盘法 · 第四章 弹簧效应（Spring）— 蒸馏笔记

> 用途：供 AI 交易分析助手在识别 K 线/成交量时直接套用的进场触发器规程。
> 核心命题：什么样的 Spring 能买、在哪买、止损设哪、目标怎么定、何时认赔。

## 方法论（作者心智模型）

Spring = 价格快速跌破支撑后又快速收回支撑上方，是一波下跌的**终止行为**。本质是一场"压力测试"：CM（主力）人为压价，观察支撑附近有没有大量卖单（供应）。若有巨量卖盘且需求全部吸收，则反弹成 Spring；若卖盘压垮需求，则不是 Spring，是继续下跌。
作者要求你用**战场比喻**思考：攻方（卖盘）打到阵地（支撑）时若兵力损失惨重（无跟随卖盘、缩量），守方（需求）立刻全力反击。所以突破时供应稀少的信号一出，聪明钱立即在支撑上买入——**在支撑上进场风险最低**，而这恰恰与公众"看到弱势就恐惧"的心理相反。
判定 Spring 永远三要素同时看：**市场大背景（牛/熊）＋ 供求关系（量价）＋ 突破与反弹的价量细节**。图形本身不指明方向，背景才指明方向。Spring 还是风控工具：进场后若市场行为否定你（反弹无需求跟随），当机立断离场。

## 核心规程（按节）

### 第一节 什么是 Spring

- 定义（识别条件）：价格迅速跌破支撑 → 1~3 根蜡烛内收回支撑上方。超时未收回，不按 Spring 处理。
- 意义：回调结束/牛市恢复，或区间交易结束/价格上扬。Spring 失败 = 牛市可能结束的重大预警。
- 心法：IF 牛市中出现回调 Spring → THEN 视为市场送出的交易机会，不可放过。IF 熊市中 → 坚决不找 Spring（重复强调：千万不要在熊市中找 Spring）。
- 突破幅度与量能决定质量：小幅突破+缩量 → 直接上涨概率大；大幅突破+放量 → 必须等二次测试（ST）。
- 仓位管理总则（大卫·威斯）：会用 Spring 和 UT（上冲回落）足以以交易为生；进场后价格必须伴随成交量持续上涨且中途不遇强大供应，否则离场。

### 第二节 Spring 的位置和种类

**位置优先级（6 类）：**

1. 牛市中回调震荡区的底部 —— 最佳位置。无量小蜡烛 Spring 可直接进场。
2. JOC 之后价格回测突破点处 —— 进场位。
3. 回测垂直需求柱底部处 —— 进场位。
4. 吸筹阶段接近尾声处 —— CM 制造恐慌收便宜筹码；若此后出现 SOS 说明吸筹结束，在测试 SOS 的回落中进场。
5. 熊市中出现 —— 陷阱，禁买。
6. 牛市中连续出现失败的 Spring —— 市场行为变化的预警信号，降低多头敞口。

**种类判定决策树（按突破蜡烛大小 × 成交量）：**

```
突破支撑时：
├─ 大蜡烛 + 大成交量（供应巨大，需求没吸完）
│   → 不是可买的 Spring；价格继续寻底。常见于熊市/吸筹右手边（此时称"震仓"）。
│   → THEN 不进场，耐心等二次测试。
├─ 小蜡烛 + 小成交量（突破时缺乏供应）★最佳
│   → 直接进场。需求会积极进入并推高价格。
├─ 蜡烛和成交量略放大（有供应但压不垮需求）
│   → 等二次测试：
│       IF ST 为缩量小蜡烛 → THEN ST 处进场
│       IF ST 仍为高量长蜡烛 → THEN 不进场（供应未耗尽）
│   → 唯一例外：放量但收在蜡烛中点之上，且大背景为牛市 → 可直接进场。
├─ 衍生变体：成交量放大 + 蜡烛不长（越小越好）+ 收在 50% 之上的下影线
│   → 含义：高量=卖方努力被需求全部吸收，收盘高位=需求获胜 → 可买。
└─ 失败 Spring：第 2/3 种形成后，反弹没有"价涨+量增"
    → 反弹失败，价格跌破支撑续跌（熊市/强供应背景常见）→ 已进场者立即离场。
```

### 第三节 案例共性检查清单（10 案例的蒸馏，非流水账）

每个案例都用同一条分析链，AI 分析时逐条勾选：

- [ ] **背景第一**：先判定大背景是需求控制（牛市/吸筹）还是供应控制（卖盘背景）。卖盘背景下一切 Spring 默认失败——案例 6/8/9 全是此类。
- [ ] **下跌前奏**：下跌过程是"小碎步+低量"（无供应、无力度、不可持续）还是"长阴+放量"（供应扩大）？前者利于 Spring 成功。
- [ ] **支撑的来历**：支撑必须是前期已经建立的强支撑（如 X 柱底部大量买单、JOC 突破点、垂直需求柱底）。无来历的支撑不算数。
- [ ] **Spring 本身的价量**：对照第二节决策树定种类，决定"直接进场"还是"等 ST"。
- [ ] **ST 质量**：合格的 ST = 成交量与高低价差都大幅萎缩（对照：恐慌抛售 5.1 万手 vs 成功 ST 5000 手）。ST 仍放量 → 供应未耗尽，不买。
- [ ] **进场后验证（命门）**：进场后 MUST 看到持续上涨 + 成交量递增 + 中途无强大供应（更高的高点/低点/收盘价）。IF 反弹后 1-2 根 K 线无跟随（尤其出现放量阴线）→ THEN 立即离场，该 Spring 判失败。
- [ ] **Spring 后一根 K 线判供需**：Spring 之后收阳线 = 需求吸收供应后仍有剩余（需求过剩）→ 看涨；继续收阴 = 供应有剩余 → 看跌。
- [ ] **失败后的新阻力**：Spring 失败后若出现放量大阴线（如蜡烛 2），其顶部 = 供应区/阻力；想再买，至少等价格突破该阴线顶部（新需求吸收了那批卖盘）。
- [ ] **Spring 高度判趋势**：Spring 引起的上涨若不能突破震荡区顶部 = 没有带来牛市，价格将回落，甚至跌破底部。
- [ ] **吸筹尾声的确认链**：恐慌抛售（跌破超卖线+急速）→ 成功 ST（量远小于恐慌抛售）→ 供应测试三选一（底部震仓 / Spring / 顶部 JOC）→ SOS → 牛市确认。链条没走完前，耐心等待。

**案例中的具体止损/目标设定（全书少有的硬数字，照抄）：**
- 牛市回调 Spring 止损：放在**突破的最低点**下方。
- JOC 回测处 Spring 止损：放在 **JOC 蜡烛底部下方 2 个点**（p151 案例）。
- UT（上冲回落）做空：止损放蜡烛顶部上方 1 个点；第一目标 = 下方支撑位（p144 案例）。
- 垂直降价柱（SOW）高点 = 主要供应区：价格回涨至此 = 做空进场点/目标位；若被强力需求柱突破 = 恢复牛市。
- 目标管理：进场后看 Spring 能否把价格带出震荡区；带出后遇"空中急速上涨（未过任何阻力）"警惕抢购高潮（派发前奏），启动风控；若急涨是**突破重要阻力**所致，属正常上涨。

### 第四节 使用 Spring 的纪律

- Spring 不是每天都有。IF 没有符合条件的 Spring → THEN 等，等待本身就是策略，不要刻意造信号。一旦出现 → 不犹豫。
- 成功率高的 Spring 只在上升趋势中；卖盘控制背景禁用（第三次重申）。
- 突破时量相对放大 → 必须等 ST，且 ST 必须是量+价差双萎缩。
- 进场前设好止损。进场后 IF 不是"持续新高阳线+递增成交量" → THEN 立即出场，等下一个 ST。
- 用 Spring 同时衡量两件事：突破时的供应量（要小）与反弹时的需求量（要递增）。两者都满足才叫正确的 Spring。

### 第五节 总结（作者最终心智模型）

- 前提：支撑必须是**前期已建立的强支撑**，支撑价位附近需求强劲。跌破后无卖盘跟随 → Spring **可能**形成，但不保证成功——必须再参考供求关系、价量行为、大背景。
- 趋势判断：上升趋势中的 Spring 成功率最高（背景就是过滤器）；下降趋势中的 Spring 对专业做空者是做空信号（利用 Spring 常失败这一行为）。
- 反弹高度意义：Spring 涨不破区间顶 → 未带来牛市 → 价格回落；回落到底部若无需求接盘 → 跌破底部。
- 最终心法：突破未带来巨量卖盘（供应耗尽）→ 立刻买入，止损放突破最低点。这种进场与公众心理相反——公众见弱恐惧不敢动手，聪明钱知道支撑上风险最低。

## 速查表

| 场景 | 动作 | 止损 |
|---|---|---|
| 牛市回调，小蜡烛+缩量 Spring | 直接买入 | 突破最低点下方 |
| 牛市，放量突破但收在中点上方 | 可直接买入 | 突破最低点下方 |
| 放量长蜡烛突破（有供应未耗尽） | 不进场，等 ST | — |
| ST 量+价差双萎缩 | ST 处买入 | 突破最低点下方 |
| ST 仍放量长蜡烛 | 不买，供应未耗尽 | — |
| 吸筹尾声：Spring→SOS | 测试 SOS 的回落中买入 | SOS 低点下方 |
| JOC 回测处 Spring | 买入 | JOC 蜡烛底部下方 2 点 |
| 熊市/卖盘背景出现 Spring | 禁买（陷阱）；做空者视其为做空信号 | — |
| 进场后无"价涨量增"跟随 | 立即离场 | 已触发 |
| 牛市中连续 Spring 失败 | 预警信号，减多头敞口 | — |
| 反弹后遇"空中急涨无阻力突破" | 警惕抢购高潮，准备风控 | — |

**反模式（公众常见错误 / Spring 失效情形）：**
1. 熊市中拿 Spring 抄底——无数抄底者的噩梦；熊市只有需求扩大才能终止，反弹无量=没有需求。
2. 只看图形不看背景——卖盘控制背景下的 Spring 必然失败（案例 6/8/9 共同教训）。
3. 放量突破时急于进场——供应未耗尽时进场，被随后的 ST 失败套牢。
4. 进场后不看跟随——反弹无量能递增就是"无需求反弹"，支撑将失效；正确做法是看到无跟随立即离场，而非补仓。
5. 跌破支撑的大阴线出现后急于在更低价买——该阴线顶部是供应区，至少等突破其顶部才考虑重新进场。
6. 刻意制造 Spring 信号——不符合条件的硬上，等于没有风控。
